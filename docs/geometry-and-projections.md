# 几何与投影

## 艺术底图，不是 GIS 面数据

`source_map.svg` 没有可验证的 CRS 或地理配准信息。它以白色开放线稿表达国界、海岸与湖泊，绝大多数 path 不是闭合多边形，因此 MapTool 不把它自动闭环、面化，也不推断国家填充。国家/地区代码、湖泊层、源 path ID 和原始 `closed` 标志仅用于保留已有语义。

首版采用可逆的 **artistic Plate Carrée** 标定：把 `ocean` 内框线性映射到全球经纬范围，Y 轴向下：

```text
longitude = (x - xMin) / (xMax - xMin) * 360 - 180
latitude  = 90 - (y - yMin) / (yMax - yMin) * 180
```

反变换使用同一边界和版本。这个选择让默认等距圆柱输出尽量保持原 SVG 的视觉比例，也让线稿可包裹到球面；它只表示艺术上的近似经纬标定，不应被用于测量距离、面积或行政边界精度判断。

## 开放路径与渲染

编译器会应用 SVG 祖先 transform，并对直线、三次贝塞尔曲线做自适应细分。每个 `M` 子路径保持独立；只有源数据本来带 `Z` 时才标记为闭合。裁剪与投影都按折线 run 处理，不会跨空隙补线。

源平面标定为经纬度后，渲染管线先在经纬空间裁剪，再投影和按屏幕误差加密。Canvas 预览、SVG 与 PNG 预期消费同一种 renderer-neutral `RenderPlan`，减少不同输出之间的算法漂移。

## 日期变更线与跨缝范围

范围模型是 `west/east/south/north` 加显式 `wrapsAntimeridian`：

- 普通范围要求 `west < east`；
- 跨日期变更线范围要求 `west > east`，含义为 `[west, 180] ∪ [-180, east]`；
- 全世界是唯一的普通区间 `[-180, 180]`；零宽范围无效。

连续线稿会相对范围中心解包；跨 ±180° 的段在缝处插入一对 `+180/-180` 端点并分成两个 run，避免出现横穿整张地图或穿球的伪长弦。跨缝范围在连续的解包窗口内裁剪，显示时再回到规范经度。

## 投影

当前投影 ID 与用途如下：

| ID                             | 名称                     | 性质与适用场景                         |
| ------------------------------ | ------------------------ | -------------------------------------- |
| `plate-carree`                 | 等距圆柱（Plate Carrée） | 原艺术线稿的默认形状基准；经纬线等间距 |
| `mercator`                     | 墨卡托                   | 保角，适合中低纬；高纬面积急剧放大     |
| `equal-earth`                  | Equal Earth              | 等积，适合全球专题图                   |
| `natural-earth-1`              | Natural Earth I          | 世界尺度的柔和折衷外观                 |
| `winkel-tripel`                | 温克尔三重               | 综合折衷面积、方向与距离变形           |
| `lambert-azimuthal-equal-area` | 兰伯特方位等积（LAEA）   | 以范围中心定位，适合区域、半球与极区   |

创建投影时，柱状/伪柱状投影保持北向上；默认中央经线取解包后范围中心。方位投影以范围中心旋转。系统对范围边界自适应采样后等比 fit 到画布和 padding，不能只按现有线稿内容 fit，也不分别拉伸 X/Y。

### 墨卡托限制

墨卡托在两极发散。MapTool 的有效纬度界限是约 `±85.05112878°`。超出时应保留用户输入的精确范围并把投影标为不可生成/导出，而不是静默钳位纬度。因此“全世界”范围不能直接用墨卡托完整表达。

### LAEA 限制

LAEA 保持面积，并以选区中心为投影中心；中心的球面反足点是奇异位置。若范围包含或逼近反足点，验证应明确报告问题，而不是遗漏内容。方位图边缘的形状和方向变形仍可能很大，“等积”不等于处处形状准确。

## 范围边界

MapTool 首版只支持经纬矩形，不支持任意多边形选区。边界曲线会被采样并用于投影后 bounds；空海域范围也应按范围边界 fit，而不是因没有线稿而改变构图。
