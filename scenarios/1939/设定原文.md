## 一、编制基准

制作一套可在 MapTool 中加载、着色、调整标注并导出 PNG、SVG、JSON 的全球政治地图预设。疆域依据采用前十二章正文、章首题铭、本次补充及已确认的选择。正文以外的具体疆界、国号和行政制度，作为本方案新增设定冻结。[正文目录](D:/Repo/PeaceSenshado/Main/PeaceSenshado/00_Manuscript)

地图固定于1939年1月1日。克里米亚已由俄联邦控制，波希米亚处于德意志王冠监护之下，英属美洲联合领正在推进二元帝国法案。

政区同时记录名称、首府、政治身份、主权所属、实际管理者和上级关系。国家、自治领、殖民地、保护国、羁縻地区、租借地、国际自由港与托管领均有独立编号。

## 二、全球国界与国家重置

### 东亚大陆

| 政治实体 | 疆域与制度 |
|---|---|
| 中华共和国，南京 | 本土覆盖关内各省、台湾、海南。南北界东起山海关，循长城关隘经过喜峰口、古北口、独石口至张家口，再接晋陕甘与蒙古盟旗的历史边界。北京、天津、山西、陕北、宁夏及河西走廊归南京。 |
| 中华帝国，盛京 | 奉天、吉林、黑龙江构成帝国本土。东北外界取黑龙江、乌苏里江及现存中俄界段，俄属滨海地区归俄联邦。热河及长城以北草原接蒙古王公联盟。 |
| 内蒙古王公联盟 | 属盛京宗主体系，辖察哈尔、哲里木、昭乌达、卓索图、锡林郭勒、乌兰察布、伊克昭及阿拉善、额济纳诸旗。王公管理旗地、宗教与地方税收，盛京掌握外交、干线铁路和驻军权。鄂尔多斯纳入联盟。 |
| 外蒙古王公联盟，库伦 | 喀尔喀四部、科布多组成半自治联盟，接受盛京册封。内外蒙古之间显示盟界，国家外轮廓统一归盛京宗主体系。 |
| 唐努乌梁海羁縻区 | 以唐努山、萨彦岭及叶尼塞河上游盆地为范围，列为盛京所属的地方王公辖区。 |
| 新疆都督府，迪化 | 属中华共和国的边疆军政区，内部区分伊犁军府、准噶尔边务区、南疆回部自治辖区。伊犁河谷、天山两侧及塔里木盆地共同构成其疆域。西界衔接俄属七河、帕米尔与阿富汗。 |
| 乌斯藏都督府，拉萨 | 属中华共和国的羁縻地区，辖卫、藏、阿里及藏北。拉萨地方政府管理宗教和地方事务，南京掌握对外关系与驻防。门隅、珞瑜山地划入都督府，南界落在藏地山地与阿萨姆平原的地形过渡带。 |
| 青海与西康 | 青海辖青海湖盆地、柴达木、玉树及果洛。西康都督府以康定为治所，涵盖甘孜、昌都康区。乌斯藏东界依唐古拉山及怒江、澜沧江流域间山地重建。 |
| 日本帝国，东京 | 日本列岛、琉球、千岛及西太平洋所属岛群构成本土与岛屿行政区。朝鲜另设殖民行政单位。 |
| 朝鲜总督府，京城 | 朝鲜半岛、济州岛、郁陵岛及附属岛屿归日本帝国委任的总督府管理。半岛北界取鸭绿江、图们江及长白山界段。 |

中国沿海另绘三类特殊行政区域。

- 英属香港包括香港岛、九龙割让区及新界租借区。葡属澳门包括澳门半岛、氹仔、路环。广州湾设法国租借地，胶州湾设德国租借地，各自记录租借关系与管理者。
- 上海公共租界、法租界及天津各国租界采用城市级行政覆盖层，城市所属主权记为中华共和国。
- 台湾省辖台湾、澎湖及邻近属岛，基隆标为紫竹学园舰母港。福建沿海的金门、马祖由福建辖区管理。

### 东南亚与南亚

| 政治实体 | 疆域与制度 |
|---|---|

| 法属老挝保护国，万象 | 以湄公河东岸及老挝山地为主体，保留琅勃拉邦王室与地方行政。 |
| 法属柬埔寨保护国，金边 | 涵盖洞里萨湖盆地、柬埔寨平原及南部海岸，保留本地王室。 |
| 暹罗王国，曼谷 | 覆盖昭披耶河流域、呵叻高原及马来半岛北段。东界依湄公河与扁担山，南界接英属马来诸邦。 |
| 吕宋共和国，马尼拉 | 辖菲律宾群岛，包括吕宋、维萨亚、棉兰老、巴拉望及苏禄群岛。为中国扶植建立的独立共和国。 |
| 英属缅甸，仰光 | 伊洛瓦底江流域、若开、德林达依为殖民行政区，掸邦、克钦及钦山地另列地方自治辖区。 |
| 海峡殖民地，新加坡 | 新加坡、槟榔屿及威省、马六甲为三个主要直辖单位，纳闽另列岛屿辖区。 |
| 马来诸邦 | 霹雳、雪兰莪、森美兰、彭亨组成联邦保护邦。柔佛、吉打、吉兰丹、登嘉楼、玻璃市分别为英国保护国。 |
| 婆罗洲北部 | 北婆罗洲为英国特许公司领，砂拉越为英国保护下的拉者领，文莱为英国保护下的苏丹国。 |
| 荷属东印度，巴达维亚 | 细分爪哇及马都拉、苏门答腊、荷属婆罗洲、苏拉威西、摩鹿加、小巽他及西新几内亚。巴厘等地方王公辖区记录地方自治身份。 |
| 葡属帝汶，帝力 | 包括东帝汶、欧库西飞地、阿陶罗及雅科岛。西帝汶归荷属东印度。 |
| 英属印度，新德里 | 覆盖印度、巴基斯坦及孟加拉所在地区。直辖省与土邦分层绘制，重点单列海得拉巴、迈索尔、克什米尔、拉杰普塔纳、中央印度、旁遮普土邦及俾路支土邦。小土邦依历史政治代理署组织显示。 |
| 喜马拉雅诸国 | 尼泊尔王国为独立国家。不丹王国与锡金王国列英国保护国，分别保留本地王室及疆界。克什米尔、拉达克归英印克什米尔土邦，阿克赛钦归新疆都督府。 |
| 锡兰与马尔代夫 | 锡兰为英国直辖殖民地，马尔代夫为英国保护下的苏丹国，分别绘制。 |
| 阿富汗王国，喀布尔 | 瓦罕走廊纳入王国，北界沿阿姆河及帕米尔界段，东南界采用杜兰线体系。 |

马尼拉的城市级划分采用巴石河北岸比农多历史街区作为中国租界，既有港区及港池设国际自由港，王城区沿城墙闭合为非军事化国际战车道赛场。三处均记录吕宋主权与各自管理机构。

### 北美、中美与南美

| 政治实体 | 疆域与制度 |
|---|---|
| 美利坚合众国，华盛顿 | 辖新英格兰、中部诸州、马里兰、俄亥俄、印第安纳、伊利诺伊、威斯康星、明尼苏达、大平原、落基山及太平洋沿岸各州，并辖德克萨斯及美墨战争所得的美国西南部。阿拉斯加设直属领地。 |
| 英属美洲联合领，查尔斯顿 | 四个创始州按殖民时代沿革组织。弗吉尼亚州包括今弗吉尼亚、西弗吉尼亚、肯塔基。北卡罗来纳州包括今北卡罗来纳、田纳西。南卡罗来纳州对应南卡罗来纳。佐治亚州包括今佐治亚、阿拉巴马、密西西比。东西佛罗里达及路易斯安那的佛罗里达诸教区另设辖区。 |

| 魁北克共和国，魁北克城 | 采用大魁北克方案，涵盖魁北克、安大略、密歇根两半岛、新不伦瑞克、新斯科舍、爱德华王子岛、纽芬兰与拉布拉多。五大湖水域按湖心及连接水道分界。 |

| 北极美洲分界 | 东部北极群岛归魁北克，西部归美属西北开发区。分界依福克斯湾、兰开斯特海峡、惠灵顿水道及北向海峡连接，巴芬岛、德文岛、埃尔斯米尔岛列魁北克所属。 |
| 墨西哥，墨西哥城 | 辖墨西哥主体、尤卡坦及下加利福尼亚半岛。北界接美国德克萨斯、西南诸州。 |
| 中美洲 | 危地马拉、洪都拉斯、萨尔瓦多、尼加拉瓜、哥斯达黎加、巴拿马分别为独立共和国。英属洪都拉斯单列殖民地。巴拿马运河区由美国管理，巴拿马城、科隆归巴拿马。 |
| 加勒比独立国家 | 古巴共和国、海地共和国、多米尼加共和国分别覆盖各自主岛及属岛。波多黎各为西班牙殖民地，圣胡安为行政中心。 |
| 南美洲 | 巴西、阿根廷、智利、乌拉圭、巴拉圭、玻利维亚、秘鲁、厄瓜多尔、哥伦比亚、委内瑞拉分别建国。玻利维亚与巴拉圭采用1938年查科和约边界。厄瓜多尔与秘鲁绘实际控制线及争议标识。 |
| 圭亚那地区 | 英属圭亚那、荷属苏里南、法属圭亚那分别列示。埃塞奎博地区实际管理者记为英国，委内瑞拉主张进入争议信息。 |

英属美洲联合领的加勒比成员采用传统英属范围，细分巴哈马、牙买加及开曼、特克斯和凯科斯、背风群岛、向风群岛、巴巴多斯、特立尼达和多巴哥。百慕大列联合领的大西洋辖区。

| 白俄罗斯共和国，明斯克 | 覆盖明斯克、莫吉廖夫、维捷布斯克、格罗德诺及东部波列西耶，列《桦树条约》成员国。 |

### 俄罗斯联邦与高加索、中亚

俄罗斯联邦共和国定都莫斯科，辖欧洲俄罗斯、乌拉尔、西伯利亚、远东及克里米亚。核心州与自治、保护地区形成联邦层级。

| 自治或保护地区 | 划分依据 |
|---|---|
| 草原自治领 | 阿克莫林斯克、塞米巴拉金斯克、图尔盖、乌拉尔四个历史行政区组成，以哈萨克草原和北部铁路带为骨架。 |
| 七河自治领 | 维尔内、伊犁河上游、楚河及伊塞克湖盆地组成，覆盖东南哈萨克草原与吉尔吉斯北部。 |
| 突厥斯坦自治共和国 | 塔什干、锡尔河中下游、撒马尔罕和费尔干纳盆地组成。费尔干纳盆地设连续行政区，其内按绿洲和山口划地方辖区。 |
| 外里海自治领 | 曼格什拉克、克拉斯诺沃茨克、阿什哈巴德、梅尔夫及卡拉库姆绿洲带组成。 |
| 布哈拉酋长国 | 俄联邦保护国，辖布哈拉、卡尔希、阿姆河中游及东布哈拉山地，保留埃米尔与地方官制。 |
| 希瓦汗国 | 俄联邦保护国，辖下阿姆河、花剌子模绿洲及三角洲地方部族，保留汗廷。 |
| 帕米尔边防区 | 以俄属帕米尔驻防范围及高山盆地为依据，南接阿富汗瓦罕，东接新疆。 |

## 四、地图表现与 MapTool 接入

- **几何制作**采用1914历史底图、Natural Earth 10m海岸和基础行政区。依本方案完成合并、切分与归属重置，再生成共享拓扑。边界优先贴合山脊、河道、绿洲与历史省界，沙漠地区采用条约直线。关隘、河口、港湾及岛链节点固定，共享弧线统一简化。
- **默认画面**采用 Winkel III 投影，中央经线东经10度，6000×3400画布。海洋用浅灰蓝，文字用深灰，主权国家采用低饱和邻接避色。英国、法国、德国、俄联邦、中华共和国、盛京、日本各有稳定色系，属地通过同色相明度表现隶属关系。
- **边界与标注**提供主权国界、属地及自治边界、政区名称三个独立开关。中立托管领用浅灰蓝和管理者括注，争议地区显示实际管理者底色及主张纹理。首府、自由港、租界在适当缩放级别出现，微小属地配放大符号。
- **数据接口**增加情景定义与政区类型，记录稳定ID、名称、身份、宗主、主权、实际管理者、首府及岛群关系。`MapConfig`加入情景引用、政区配色覆盖和显示开关，`LayerData`承载政区面、共享边界及情景标注。
- **应用入口**在现有编辑器加入情景预设选择与政区颜色编辑，载入本预设时同步应用疆界、样式和中文历史地名。一次载入对应一次撤销记录，JSON往返保存同一情景版本及用户配色。
- **加载与导出**将完成的情景几何随应用打包，Canvas、SVG、PNG及逐层导出共用同一数据、投影、边界和标注布局。配置升至v6，覆盖现有v4、v5配置的迁移。

## 五、验收与补全假设

### 验收场景

- 全球政区面闭合、方向正确，共享边界一致。每个陆地组成部分具有唯一实际管理记录，争议主张作为附加信息保存。
- 核对山海关及蒙古盟旗边界、台湾与基隆、日管朝鲜、乌斯藏、独立越南、吕宋及马尼拉特殊区。
- 核对大魁北克、密歇根两半岛、美属西北开发区、英属肯塔基、印第安纳通道及墨西哥下加利福尼亚。
- 核对全夏威夷托管范围与中途岛、美国委任管理及条约中立标识。核对传统英属加勒比、西属波多黎各和独立古巴。
- 核对俄控克里米亚及乌克兰主张、中亚自治领与两保护国、北高加索自治区、奥斯曼联邦各自治地区。
- 核对德属非洲及太平洋、独立阿比西尼亚、埃及直属区、殖民地飞地与海峡岛群。

- 验证预设载入、改色、撤销重做、刷新恢复、旧配置迁移及JSON往返。对照预览检查PNG、SVG与逐层导出，执行`npm run build`和TypeScript检查。

### 本方案采用的补全默认值

- 德国的非洲和太平洋殖民地按无第一次世界大战的延续线设置。阿尔萨斯、洛林划法国，德国与奥地利合并的外围地区按语言区、山系和旧王冠领划分。

- 地图中的首府、租界位置和微小岛屿边界需在实施时完成几何及视觉验收。预设随附政区归属表与边界依据，供后续设定修订追溯。
