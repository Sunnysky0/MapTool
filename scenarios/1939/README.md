# 1939 年 1 月 1 日世界政治地图

情景标识为 `peace-senshado-1939`，当前修订号为 `2`。在编辑器的 **Layers → 情景预设** 中选择日期，再选“全球”“欧洲与近东”或“非洲”。全球图为 6000 × 3400，采用中央经线东经 10° 的 Winkel Tripel 投影。欧洲图为 4096 × 3612，采用标准纬线 40°、62° 的兰伯特等角圆锥投影。非洲图为 4131 × 3841，采用兰伯特方位等面积投影。每张图可导出 PNG、SVG 和可重开的 JSON，首版 JSON 仍调用随应用附带的首版疆界和配色。

默认“1938 原图”主题取自已有世界设定地图，采用近黑海面、宗主国底色、粉色边界和蓝灰色河网。欧洲图采用区域排版的国名、白描边字形和浅粉首府星，非洲图采用无名城市点和离岛定位圈。欧洲的弧排国名字体现用本机方正北魏楷书，其他设备使用楷体或中文衬线字体。字形外观取决于当地字体。非洲图可启用“政区名称与地名”显示文字。**Style → 浅色印刷** 提供浅底方案。政区、边界、水系、铁路、城市、标注均可单独导出。城市点与铁路是地理定位参考，资料反映现代 Natural Earth 制图概化。

政区面、归属表和名称按本次修订重新生成。英文稳定编号可用于检索，改色可作用于父政区和下属领地。标注偏移以宽 1920 的参考画布为单位，随输出等比缩放。[全球 PNG](../../output/1939/1939-01-01.png) · [欧洲与近东 PNG](../../output/1939/1939-01-01-europe.png) · [非洲 PNG](../../output/1939/1939-01-01-africa.png)

政区主表记录稳定编号、中文名称、首府、身份、主权、上级、宗主、管理机构、主张方和设定依据。一个上级辖有多个下级时，以各下级的面拼合其疆域。无人岛的首府字段留空。首版设定原文保留作版本对照。[政区归属表](./政区归属表.csv) · [全球预设](./preset.json) · [欧洲预设](../../output/1939/1939-01-01-europe.json) · [非洲预设](../../output/1939/1939-01-01-africa.json) · [首版设定](./设定原文.md)

## 定界依据

| 区域 | 设定与工作几何 |
| --- | --- |
| 南京与盛京 | 第一部第 5 至 7 章的基隆母港、山海关停火线、吕宋租界与赛场。辽宁、吉林、黑龙江及蒙古盟旗按设定重分。北京、天津、晋陕甘保留在南京体系，关隘之间使用经纬度控制点。 |
| 青藏与新疆 | 伊犁、准噶尔、塔里木依据盆地和山间通道切分。康定及昌都康区、门隅与珞瑜单独定界，阿克赛钦纳入南疆。藏东山地及盟旗内部边界采用世界图尺度的重建线。 |
| 南亚及东南亚 | 英属印度全境单列一面，包含原土邦、直辖省、克什米尔和拉达克。尼泊尔、不丹、锡金、缅甸、锡兰及马尔代夫各自单列。马尼拉自由港包括码头及港池，王城区以城墙转折点闭合。 |
| 北美与太平洋 | 第 8 章题铭及议会叙述确定四个创始州和法案进度。北美州省取一级行政区，按约定合并。大湖切除水面后保留跨湖界，密歇根湖补绘湖心水界。第 9 章题铭与本轮补充确定夏威夷托管与四国中立保障。 |
| 德国与巴尔干 | 德国西界按 1871 年阿尔萨斯–洛林范围处理，采用下莱茵、上莱茵和摩泽尔三省的工作轮廓，贝尔福和南锡留法。德国还辖斯洛文尼亚、的里雅斯特及伊斯特拉半岛陆地。里耶卡、克尔克岛和达尔马提亚归克罗地亚。奥地利既定范围、受监护的波希米亚、圣斯蒂芬王国及其自治领、其余巴尔干国家均承袭首版。 |
| 波罗的海与俄联邦 | 参考欧洲 v10，爱沙尼亚与拉脱维亚合绘为波罗的联合大公国，维尔纽斯为立陶宛公国首府，梅梅尔属德国。俄联邦将北高加索、伏尔加、乌拉尔和西伯利亚并作本土。格鲁吉亚、亚美尼亚、阿塞拜疆和中亚主要民族地区分别为联邦体系下的自治单位。布哈拉与希瓦保留保护关系。克里米亚沿用俄方实控及乌克兰主张。 |
| 近东与阿拉伯 | 奥斯曼主体包括安纳托利亚、黎凡特、外约旦、伊拉克与参考图所示的也门北部。沙特采用现行国界及所属红海岛屿。巴勒斯坦托管领涵盖约旦河以西的以色列、约旦河西岸及加沙范围，剔除戈兰高地与舍巴农场；控制线以本版共享陆地及水域为准。托管机构名称与受托国均未指定。塞浦路斯保留英管奥斯曼租借地身份。 |
| 非洲 | 阿尔及利亚、利比亚、埃及、苏丹、比属刚果、德属东非、乌干达、南非等各以主要属地为单位。参考图中的南北尼日利亚、两罗得西亚、上塞内加尔与尼日尔、乌班吉沙里—乍得照其实际边界编组。西撒哈拉两处分属西班牙。北非殖民疆界和朱巴河界段取参考矢量，覆于共用海岸上。阿比西尼亚独立，1911 年喀麦隆扩界、基翁加和鲸湾港飞地沿用世界设定。 |
| 海岛与两极 | 离岸组成部分按政区登记管理者和岛群。岛名表记录显名岛群、坐标与符号。来源未分出的微小岛礁用点标注。南极大陆保留主权未定底色，标出英国、澳大利亚、新西兰、法国已公布的扇区以及挪威的彼得一世岛主张。 |

河谷、长城关隘之间的连线，殖民代理署外缘、租界和港池轮廓属于本版制图重建。城市级边界适合表达相互位置和管理关系，精度取决于控制点及原始海岸线。争议纹理不改变陆地管理记录，南海岛礁点表示地物位置，海水保持海洋底色。

## 数据与复核

运行应用与导出成图只需要随仓库提供的数据包。发布包内 `topo.objects.units` 的每个几何体保存 `unit`、`manager` 及与各 Polygon 顺序对应的 `groups`。顶层 `groups` 以编号索引岛群，`labels` 保存中文名称和标注锚点。`geography` 存储水系、铁路和城市点，`europeanNames` 保存本版欧洲国名的地理锚点和排版参数。`gazetteer.json` 提供政区索引。v6 配置保存数据修订号、图幅、主题、政区配色、标注修改与图层状态。

从仓库根目录执行以下命令，可以复核发布数据、类型与应用构建。

```powershell
node scenarios/1939/verify.mjs
npx tsc --noEmit
npm run build
```

重制几何时使用 Python 3.11、Shapely 2.1、pyshp 2.3、Node 22 或更新版本和 mapshaper 0.6.113。将上述 1:10m 数据集、同版本的 1:10m 河流及铁路、1:50m 居民点和固定版本的历史底图放入 `SOURCE_DIR`。`REFERENCE_1938` 指向现有 `PeaceSenshado/Maps/1938`，仅供重建。地理输入包括其中的非洲分区 GeoJSON、黎凡特争议地区 GeoPackage、三份色表、欧洲标注和非洲定位圈参数。参考目录保留各自的来源与许可记录。[欧洲参考说明](D:/Repo/PeaceSenshado/Maps/1938/europe_map/README_架空版.md) · [非洲参考说明](D:/Repo/PeaceSenshado/Maps/1938/africa_map/README.md) · [第二版定界规则](./revision2.py)

```powershell
python scenarios/1939/build.py SOURCE_DIR WORK_DIR
python scenarios/1939/revision2.py SOURCE_DIR REFERENCE_1938 WORK_DIR
python scenarios/1939/geography.py SOURCE_DIR REFERENCE_1938 WORK_DIR
python scenarios/1939/finish.py WORK_DIR PATH_TO_MAPSHAPER
```

生成器在原有陆地分区中转移每块几何，按共享弧线统一简化。面积小于 300 平方公里的组成部分保留详细节点。最终量化后重新建立节点，验证所有多边形有效、共享边一致且面不重叠，再输出压缩拓扑、归属表和地名。修订已发布的几何时应另立修订号，保证旧 JSON 仍可回到原版地图。
